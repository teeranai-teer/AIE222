## วิธีรัน

รันจากโฟลเดอร์ `team_1670903515/code` ด้วย Python 3.9 ขึ้นไป คำสั่งแบบสองอาร์กิวเมนต์ใช้ได้กับข้อมูลวันใหม่และเขียน CSV สามไฟล์ไว้ในโฟลเดอร์ผลลัพธ์

```sh
python solve.py ../../AI_Concrete_Student_Kit/data/day1_weekday ../new_out/day1
```

ผลที่ตรวจคะแนนอยู่ใน `out/day1` ถึง `out/day4` แผนเหล่านี้ได้จากการค้นหาต่อจากแผนตั้งต้นหลายรอบ ใช้ `--warm-start` เพื่อค้นหาต่อจากแผนที่แนบมา

```sh
python solve.py ../../AI_Concrete_Student_Kit/data/day1_weekday ../new_out/day1 110 --warm-start ../out/day1
```

ใช้ `AI_Concrete_Student_Kit/starter/evaluate.py` ตรวจ CSV โดยส่งค่า `--truth` เป็นไฟล์ JSON ที่มีเนื้อหา `{"true_lines": {"P05": 2, "P07": 3}}` สำหรับการตรวจด้วยกำลังผลิตที่อนุมาน Day 5 ยังไม่มีข้อมูลสำหรับวัดคะแนน
