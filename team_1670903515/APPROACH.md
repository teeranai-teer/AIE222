## วิธีรัน

แตก ZIP แล้วรันจากโฟลเดอร์ `team_1670903515/code` ด้วย Python 3.9 ขึ้นไป คำสั่งแบบสองอาร์กิวเมนต์ใช้ได้กับข้อมูลวันใหม่และเขียน CSV สามไฟล์ไว้ในโฟลเดอร์ผลลัพธ์

`solve.py` ใช้งบเวลาเริ่มต้น 85 วินาทีต่อวัน รวมเวลาอ่านข้อมูล ค้นหา และเขียนผลลัพธ์ โปรแกรมเผื่อเวลาให้การเขียน CSV และรับค่า `seconds` ที่มากกว่า 0 ถึง 120 เท่านั้น

```sh
python solve.py ../../AI_Concrete_Student_Kit/data/day1_weekday ../new_out/day1
```

ผลที่ตรวจคะแนนอยู่ใน `out/day1` ถึง `out/day4` ใช้ `--warm-start` เมื่อต้องการใช้แผนที่แนบมาเป็นจุดเริ่มต้น โดยมีเพดานเวลา 120 วินาทีเช่นเดียวกัน

```sh
python solve.py ../../AI_Concrete_Student_Kit/data/day1_weekday ../new_out/day1 85 --warm-start ../out/day1
```

ใช้ `AI_Concrete_Student_Kit/starter/evaluate.py` ตรวจ CSV โดยส่งค่า `--truth` เป็นไฟล์ JSON ที่มีเนื้อหา `{"true_lines": {"P05": 2, "P07": 3}}` สำหรับการตรวจด้วยกำลังผลิตที่อนุมาน Day 5 ยังไม่มีข้อมูลสำหรับวัดคะแนน
